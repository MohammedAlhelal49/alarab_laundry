account_secondary_currency_report
Secondary currency filter · Analytic Account column · Group by Analytic Account for General Ledger
Author: Dekad License: LGPL-3 Odoo 18 Enterprise Depends: account_reports · analytic · account
Features

Secondary Currency Filter

All reports

Displays debit/credit/balance in any configured currency. Journal items in the selected currency use amount_currency; others keep company currency. Rounding unit labels (kUSD, MUSD…) update automatically.

Show Analytic Account

General Ledger

Adds an optional Analytic Account column to each AML line. Toggled via Options → Show Analytic Account. Works independently of the secondary currency filter.

Group by Analytic Account

General Ledger

Restructures the report into a 3-level tree: Analytic Account → Account → AML lines. Lines with no analytic appear last under "∅ No Analytic Account". Toggled via Options → Group by Analytic Account.

Options reference
Option keyTypeDefaultScopeDescription
secondary_currency_id int | False False All reports ID of the secondary currency. When set, values are converted via per-line historical exchange rates using a LATERAL SQL join.
hide_zero_balance bool False All reports Hides accounts / partners whose net balance is zero in the selected period.
show_analytic_account bool False General Ledger Adds an "Analytic Account" column to each AML line. Column is filtered from options['columns'] when disabled.
group_by_analytic bool False General Ledger Restructures the report as Analytic → Account → AML. Lines with no analytic appear under "∅ No Analytic Account". When off, super() is called unchanged.

Performance design
1
SQL query for analytic totals — single UNION ALL across all column groups
0
Extra joins at top level — analytic_account_id is a stored field, no runtime join
Lazy
Account and AML lines load on expand only — no eager loading
Safe
When group_by_analytic is off, super() is called directly — zero overhead

Installation
1. Copy module to addons pathPlace account_secondary_currency_report/ alongside your other custom addons.
2. Update apps list and installSettings → Apps → Update Apps List → search "account_secondary_currency_report" → Install.
3. Upgrade (not restart) when updatingThe account.report.column record for Analytic Account is created on install/upgrade. A server restart alone won't create it.
4. Enable Analytic AccountingAccounting → Configuration → Settings → ✅ Analytic Accounting.
Known constraints
Group by Analytic is General Ledger only. Trial Balance and Partner Ledger aggregate at account/partner level — the option key is not injected on those reports.
Multi-analytic distribution. When a line has multiple analytic accounts (e.g. {"5": 60, "8": 40}), only the first key is stored. The line appears under one analytic group only.
Historical data requires recompute. Lines posted before installation have analytic_account_id = NULL. Run env['account.move.line'].search([('analytic_distribution','!=',False)])._compute_analytic_account_id() from Odoo shell to backfill.
