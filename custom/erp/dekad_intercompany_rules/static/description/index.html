⚙️ Dekad Intercompany Rules

A unified module enforcing two intercompany business rules: automatic PO locking when the linked SO is confirmed, and receipt quantity locking to prevent unauthorized changes.

Odoo 18 Enterprise · Inter-Company

Business Rules

🔒 Rule 1 — PO Lock on SO Confirm

When Company B confirms the intercompany SO generated from Company A's PO:

  • PO lines become read-only
  • Cancel button is disabled
  • Unlock button is hidden
  • Auto-unlocked if SO is cancelled or reset to Draft

📦 Rule 2 — Receipt Quantity Lock

When a Receipt is linked to an intercompany PO:

  • Done quantity on each move line becomes read-only
  • Prevents buying company from changing received quantity
  • Applies after selling company validates the delivery

Behaviour by State

SO State (Company B) PO State (Company A) PO Lines Editable Cancel Available Unlock Button Receipt Qty Editable
Draft / Sent Purchase (Confirmed) ✔ Yes ✔ Yes — ✔ Yes
Sale (Confirmed) Done (Locked) ✘ No ✘ No ✘ Hidden ✘ No
Cancelled / Reset to Draft Purchase (Restored) ✔ Yes ✔ Yes — ✔ Yes
Note: POs locked manually by a Purchase Manager are not affected. The intercompany_locked field distinguishes intercompany locks from manual locks.

Migration: Lock Existing POs

Run after installing the module to lock POs created before installation:

confirmed_sos = env['sale.order'].search([ ('state', '=', 'sale'), ('auto_purchase_order_id', '!=', False), ]) pos_to_lock = env['purchase.order'] for so in confirmed_sos: po = so.auto_purchase_order_id if po.state == 'purchase': pos_to_lock |= po pos_to_lock.sudo().write({ 'state': 'done', 'intercompany_locked': True }) env.cr.commit() # Note: Run AFTER upgrading the module
